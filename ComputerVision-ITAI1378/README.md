# Computer Vision - ITAI 1378

## Course Overview

This course explores fundamental and advanced computer
vision techniques through practical AI laboratory projects.

## Projects

| Project | Description |
|---|---|
| [L02 - Image Processing](L02-Image-Processing/) | Image enhancement, filtering, and transformations |
| [L03 - Classical Machine Learning](L03-Classic-Machine-Learning/) | Feature extraction and image classification |
| [L06 - Object Detection](L06-Object-Detection/) | Object detection and segmentation using YOLO11 and SAM 2 |
| [L08 - Vision Language Models](L08-Visual-Language-Models/) | Image understanding and visual question answering |

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- PyTorch
- YOLO11
- SAM 2
- Hugging Face Transformers
- Google Colab

## Learning Outcomes

- Apply image processing techniques.
- Implement classical machine learning algorithms.
- Perform object detection and image segmentation.
- Explore Vision Transformers and Vision Language Models.
- Evaluate AI model performance and limitations.
